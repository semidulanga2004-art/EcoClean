# EcoClean park source assets

Original Blender kit generated for the approved park concept. Editable source: EcoClean_Park_Kit.blend. Exported FBX models live in Assets/EcoCleanPark/Models. Keep these sources for the assignment submission. The generator is included to make geometry edits repeatable; save artistic edits as a new Blender file before running it again.

Unity environment scene: Assets/EcoCleanPark/Scenes/Park.unity. No player character is included. The PlayerSpawn marker is the integration position for the gameplay team. The overview camera is for environment preview, not a player controller. Fountain prefab: Assets/EcoCleanPark/Prefabs/WorkingFountain.prefab. Press Play to run spray, ripples and positional audio. ParkFountain has no player or gameplay dependencies.

Bin categories and colours are provisional and must match the team's researched sorting rules. Litter models are visual placements only, without pickup logic. This environment does not implement AI, scoring or progression.

AI assistance: OpenAI Codex was used for concept images, model generation, scene assembly and fountain code. Credit this assistance in the project report as required by the brief. The 19 generated model files are not a guarantee that all qualify as distinct assessed original assets; the team should review, edit and explain its own contribution.

Third-party kit: Low Poly Environment Park by Palmov Island, Unity Asset Store package 242702, version 1.0.0. Imported through the user's Unity account. The Unity Park scene includes 127 instances of the kit's trees, benches, stones and grass, with a separate URP-compatible material in Assets/EcoCleanPark/Materials. The downloaded material and model files remain unchanged. Credit this pack in the report and game credits. The Blender library and Blender environment are the custom source version; the final Unity scene also uses the third-party kit. A backup of the custom-only Unity scene is saved as Park_CustomBackup.unity.

The environment generator is available under EcoClean > Build Park Environment. It replaces the Park scene, so save manual scene edits separately before invoking it. It does not replace the team's other scenes or change the build scene list.
